# Cycle Catalog

Index of all predefined iteration cycles.

| # | File | Name | Purpose |
|---|------|------|---------|
| 1 | [1-ui-refinement.md](./1-ui-refinement.md) | UI Refinement | Iteratively improve the look, feel, and usability of UI components until they meet a high visual and interaction quality bar. |
| 2 | [2-feature-implementation.md](./2-feature-implementation.md) | Feature Implementation | Build new features from requirements through to human-approved quality. This is the workhorse cycle — the one most features will use. |
| 3 | [3-roadmap-planning.md](./3-roadmap-planning.md) | Roadmap Planning | Create and refine a prioritized development roadmap through research, synthesis, and human conversation. This cycle produces `roadmap_items`, not code. |
| 4 | [4-bug-triage.md](./4-bug-triage.md) | Bug Triage | Systematically identify, reproduce, root-cause, fix, and verify bugs. This cycle emphasizes *proof* — a reproduction test must exist before a fix is attempted, and it must pass after. |
| 5 | [5-documentation.md](./5-documentation.md) | Documentation | Create and refine documentation through iterative drafting, expert review, and editorial polish. Produces documentation that is accurate, complete, clear, and well-structured. |
| 6 | [6-architecture-review.md](./6-architecture-review.md) | Architecture Review | Evaluate and evolve system architecture through structured analysis, proposal, adversarial challenge, and human decision-making. This cycle produces *decisions*, not code — though it may end with initial scaffolding. |
| 7 | [7-release.md](./7-release.md) | Release | Prepare and ship a release with quality confidence. This cycle is linear — it doesn't loop back to the beginning, but individual stages can retry on failure. |
| 8 | [8-onboarding-dx.md](./8-onboarding-dx.md) | Onboarding / DX (Developer Experience) | Improve the developer and user onboarding experience by systematically finding and eliminating friction. This cycle simulates a fresh user experience and iterates until onboarding is smooth. |
