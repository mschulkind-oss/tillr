Provenance Contract & Keyboard Controls

Epistemic Provenance Marks (Zero, Missing, Derived Never Share a Mark)

● observedDirectly recorded timestamp, exit code, hash, or verdict in store/trace.
~ derivedComputed at read time from viewer clock, file mtime, or hold rule. Never presented as recorded.
≥ lower boundSum where at least one run reported no usage count.
⚠ unobserved seamCausal step or boundary check with no per-run record, or unverified worker claim.
∅ absent / not recordedNo clock, file, or field was written. Never displayed as 0 or —.
✕ corrupt / unreadableStored JSON or artifact failed parse or hash verification.
⧉ lane copyRead from mutable lane worktree rather than immutable loop archive.
